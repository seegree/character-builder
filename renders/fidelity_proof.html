What this proves

  • Vector reaches this tier. Every mark is an AE shape or effect — no imported art.
  • Stripes clip to cloth via an alpha track matte; they run continuously across body and sleeves.
  • Texture is a real pass now (grain adjustment layer), not the invisible one from before.
  • Rig-ready: front-facing, hose-limb skeleton — the parts map onto the rig we built.

Where mine still differs

  • Pose: mine is front-on & symmetric; the ref is a 3⁄4 turn.
  • Hair: mine is a rounder, tidier poof; the ref is an asymmetric messy bob with fine flyaways.
  • Eyes: mine are outlined; the ref’s are near-solid black with a catchlight.
  • Line: mine is clean; the ref has a slightly rough, hand-drawn ink edge.

What it costs & means

  • All the gaps close with more path iteration + a roughen/line-boil pass + light interior shading — same technique, more art.
  • One rich part = a small set of bezier shapes (a striped garment = base + stripes + matte + outline).
  • Now we can size the part library knowing that cost, and cap variants per slot so it stays bounded, not a million parts.
The question this answers: yes — a single character at the fidelity of a reference is achievable in AE vector, and rig-ready. Next we decide the part-library plan: which slots, how many variants each, and how the richer parts ride the rig.
